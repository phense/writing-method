# Short piece template

On instantiation, change `type` to `short-piece`, remove `template_type` and set the actual ID, story ID and canon status. Use this template only when the form in the story brief is `short-form`. One note holds one piece. Store the note in `06-manuscript/pieces/` and list it in the manuscript index.

Only the text under the heading `## Manuscript` is manuscript. That section ends at the next heading of the same level, so the prose itself uses no level-two heading. Everything outside it is a working note.
